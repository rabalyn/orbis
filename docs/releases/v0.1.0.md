# Orbis 0.1.0

The first stable release of Orbis brings together the globe and five-projection flat map, with support for Earth, the Moon, Mars, Mercury, Ceres and Vesta.

## Highlights

- Explore electricity generation on the globe and map, from country and state summaries down to power plant sites, with output, demand, monthly charts and carbon intensity.
- Import and display GeoJSON, GPX, KML, KMZ and IGC data. Create altitude-aware measurement trails, inspect each leg's distance and elevation change, manage a saved track library, and export GPX.
- See named surface features, rover and mission tracks, and information pages across supported bodies.
- Use the browser build, configurable map services, saved places, event feeds, frame recording and screenshot tools.

## Notes

- File import and GPX export are available in the desktop app; the browser build does not support local file import.
- Terrain elevation is used for measurements where elevation tiles are loaded. Otherwise, the segment uses surface distance without an elevation adjustment.
- Known automated testing gaps for live-window interactions and file drops are listed in `docs/TESTING.md`.
